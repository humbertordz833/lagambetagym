# La Gambeta Gym — página web

Sitio de La Gambeta Gym (Presidente Franco, Paraguay): https://lagambetagym.netlify.app

| Carpeta | Qué hay |
|---|---|
| `public/` | Lo que se publica en Netlify (`index.html` con las fotos incluidas y la imagen para compartir). |
| `fuente/` | Plantilla editable, fotos, y los scripts para armar la página (`construir.py`), el equipo y las reseñas. |
| `propuesta/` | Propuesta comercial (HTML para generar el PDF) y sus capturas. |
| `entregables/` | Propuesta en PDF y video instructivo con voz y subtítulos. |

Para actualizar: editar `fuente/plantilla.html`, correr `python3 fuente/construir.py` y subir los cambios a `main`.
Más detalle en `CLAUDE.md`.
